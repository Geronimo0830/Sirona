# Sirona

**一款 Windows 上的本地小说工作台。**

## 为什么做 Sirona

我在市面上找了一圈，想找一个能在本地写长篇、随手查人物和设定的工作台。试过几款之后，还是没找到顺手的。有的 AI 功能需要额外订阅，有的把按钮、面板和设置挤在同一屏。我打开软件时，往往只想接着写昨天那一章。

有了 AI，即使是第一次写小说，也可以试着把自己想看的故事写出来。卡在某一段时，可以请它想几个走向。知道接下来怎么写时，就回到正文继续。

所以我做了 Sirona。**中央写正文，左侧是目录，人物、设定和 AI 助手按需在右侧打开。** 新建作品后，先从一章空白正文开始。卷怎么分、人物属于哪个势力、世界设定怎么整理，都可以写到用得上的时候再决定。

## 名字的由来

> *Deae Deironae,*<br>
> *Maior Magiati filius votum solvit libens merito.*
>
> 献给女神西罗娜。马吉阿图斯之子迈奥尔，欣然还愿。

—— 法国圣方丹出土的拉丁文奉献碑。缩写已补全，中文为意译。[法国文化部馆藏记录](https://pop.culture.gouv.fr/notice/joconde/00150070341)

**Sirona** 取自凯尔特信仰中与泉水及疗愈有关的女神。*Deirona* 是她在这块碑上的写法。在罗马时期的高卢及周边地区，她的名字也见于一些泉水圣所的铭文。[相关考古与铭文研究](https://olh.openlibhums.org/article/4414/galley/8023/download/)

我喜欢这个名字和泉水的联系。小说起初也许只有一段对话，或者一个还没有名字的人。我想做一个地方，把这些最初的念头写下来，下次打开时，还能从那里接着写。

## 写作与整理

- **正文**可以分卷、自定义卷名和调整章节顺序。移卷后，目录会定位到章节的新位置。
- **人物和设定**都可以自由写。人物可按自建势力归类，设定可按地点、规则或你自己定义的类别整理。
- **专注模式**收起两侧面板。正文支持自动保存、历史版本与回收站，也可用 `Ctrl+S` 手动保存。

## 按需使用 AI

Sirona 可以离线写作。需要 AI 时，在「设置」填入自己的 API 地址、模型名和 API Key。支持兼容 Chat Completions 的接口和 DeepSeek 适配，调用费用按所选服务商的规则计算。

发问前，可以选择带上整章或一段选中文字，也可以勾选人物与设定。在「查看实际发送内容」里确认材料后，点「发送」才会发出对话请求。回复可以先预览、编辑，再决定插入正文或替换选段。采纳后可用 `Ctrl+Z` 撤销。

## 从源码启动

当前为 **0.1.0 开发版**，已在 Windows x64 和 Node.js 24 上验证。在项目根目录打开 PowerShell，运行下面两条命令。

```powershell
npm ci
npm run dev
```

启动后选择「新建作品」，取名并选择保存位置。Sirona 会创建作品目录和一章空白正文。

## 导入、导出与备份

- **导入旧作品**会把支持的 DSH 小说工作台资料复制到新目录。
- **导出正文**会按卷和章节的顺序生成 TXT。
- **备份整个作品**会一并复制正文、人物、设定、对话和历史版本。原稿以 Markdown 保存在作品目录里。
